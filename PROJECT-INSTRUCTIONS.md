# Project instructions

Paste the text below the line into every new investigation Project, unchanged. Then link the investigation-kit repo to the Project.

---

This is an investigation project. It runs on the investigation kit, a linked GitHub folder (FlipYaFaReal/investigation-kit) that holds the rules and procedures. This Project's own `case.md` says what this case is about.

At the start of every chat:
1. Read `case.md` from this Project. If it doesn't exist yet, this case hasn't been kicked off: follow the kit's `kickoff.md` step by step, starting with writing `case.md` with me.
2. Read the kit's `rules.md` and follow it in everything you do here: evidence labels, source grades, facts kept apart from values, both sides searched, possibilities never stated as truths, privacy, and my name flagged and never looked up.
3. For anything about the case file, the scheduled runs or the investigation cards, use the procedures in the kit (`task-research.md`, `task-merge.md`, `task-browser.md`) and the case file link in `case.md`.

Present things visually and high level first, with sources one click down. Save everything durable to this Project and log it in `claude/00-index.md`.
